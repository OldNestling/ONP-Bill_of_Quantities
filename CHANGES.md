# Список изменений

## Изменения версии 1.0.4.1

- Ускорение работы с файлами json:
  - стандартная библиотека "json" была полностью заменена на более быструю "orjson"
  - чтение всех файлов ведомостей теперь распределяется по потокам

- исправлен баг генерации xml-структуры без флага `without_resources`,
  когда тег-контейнер создавался для каждого ресурса, что нарушает xsd-схему
